# 1.4.25 本地新标签页验证记录

本次把正式前端打包进扩展，用同一套组件呈现缓存和在线数据。原独立缓存列表、隐藏 iframe 交接及相应旧控制器已经移除。保留现有 Cookie 登录、版本冲突检查和收藏 Token 接口；没有增加数据库、轮询、差量同步协议或离线写入队列。

额外恢复流程 7 项通过：失效主地址与 450 ms 备用地址、保留 200 ms 用户探测值、设置变化时保留草稿并停止提交、实际读取超时后继续搜索、离线菜单保留主备链接、缓存损坏时仍能输入并用 Enter 打开地址、错误 Token 明确报鉴权失败，以及显式直达模式仍能打开服务端页面。相关断言按连续用户流程归为 7 项。

已发布的 1.4.22 Chrome 解压包配合新服务端完成登录、书签展示和旧 iframe 缓存桥接，确认可先升级服务端。

## 发现后修正的边界

- 解锁保护场景期间，普通展示快照不再取代已经验证的场景目录，避免自动切回普通场景。
- 缓存启动不再用延后的动画帧把空过渡输入复制回正式输入框，避免抢先输入的文字被清空。
- 空列表和错误状态不再卸载尚未关闭的编辑器；后台删除不丢失草稿。
- 刷新同时涵盖导航、显示设置和展开偏好；保留用户当前的本地展开选择。
- 退出前后均使旧快照失效，取消旧鉴权读取；手动清缓存与权限撤销分开处理。

## 范围与未覆盖环境

同一扩展标签页选定连接后不会自动跨地址重放写操作；配置变化时停止提交并保留草稿，跨网后可打开新标签页重新选址。缓存中的普通内容可以离线使用，但缓存没有权限证明或备份作用。

真实 MacBook、Microsoft Edge 本体、生产 NAS/HTTPS 反代、真实商店升级与审核没有在本机代为验证或执行。Edge 测试指在隔离 Chromium 中加载 Edge 身份及其构建。普通网页完全断网后的应用资源加载不属于本次 PWA 能力；扩展资源已本地打包。

服务端配置格式不变。使用、升级、包的选择及回退见 [书签缓存说明](bookmark-cache.md)；本记录不代表已部署生产环境。

## 候选版本与设置迁移补充

1.4.24发布后的最终核对发现旧版默认直达设置只修改超时并保存时，可能与界面显示的本地模式不一致。最终交付为1.4.25：启动、选中状态和保存值复用同一条规则，旧模式保存为本地，明确选择的直达模式保留。四种存量设置的回归和实际设置页点击保存均纳入核验。该问题已在1.4.24实际设置页复现；1.4.24现已改标预发布，不作为本次最终交付；旧标签和记录保留，不覆盖已发布历史。
