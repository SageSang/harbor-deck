# 实现审查修复与验证

基线：`8b37580`（1.4.18）。本次只修改工作区，不发布、不更新线上容器。

## 修复范围

- 分组状态仅在写入成功后广播；接收广播后的回读不再广播。读取失败可重试，也可临时展开浏览而不覆盖服务器偏好。
- Web 导航及整站读取过滤锁定场景；保存可见配置时服务端保留锁定内容，拒绝隐藏书签标识碰撞和未经解锁的修改。场景访问状态变化会取消并移除旧查询缓存。
- 导航与系统草稿携带自己的版本。系统及整站保存具有并发保护，版本元数据不写入持久配置或导出 JSON。
- 编辑草稿不随后台刷新重置；提供版本比较、显式重新加载、关闭确认及页面离开提醒。不同设置页的保存只提交对应内容。
- 自动备份采用分段计时并重新核对到期时间；配置保存不等待远端备份调度刷新。
- 主题保留在本机浏览器；服务端仅提供首次默认值。扩展跳转参数不覆盖本机选择。
- 普通书签支持 URL 和备注搜索；快速记录具有数量入口、完整列表、编辑和批量归组。
- 不再用第一个书签推断网络；无完整探针时显示未知。可重新检测，双地址书签菜单可分别打开主地址、备用地址。
- 书签使用真实链接；补充显式操作菜单、键盘焦点管理、嵌套弹窗 Escape 行为和窄屏布局。

## 隔离生产构建与浏览器验证

使用临时配置目录和虚构测试账号，在回环地址运行生产构建；未读取线上书签或 WebDAV 凭据。

- 备注搜索能找到普通书签。
- 外部客户端新增分组后，旧编辑提交被拒绝；未保存标题保留，显式重新加载后能正常保存；外部新增分组未丢失。
- Escape 关闭放弃确认框后，底层编辑器和输入仍保留；图标选择器可获得焦点、搜索，并逐层关闭。
- 两条快速记录批量归组后入口计数从 2 变为 0，目标分组具有两条引用。
- 私密场景解锁后内容可见；结束场景后私密内容从页面消失。
- 本机切换浅色并刷新后仍为浅色，持久配置中的服务端主题仍为深色。
- 两个同源标签页同步分组展开；回读计数在观察间隔内保持不变，不再循环。
- Ctrl 点击打开新标签，原导航页保留。
- 390 像素视口检查顶部入口、分组计数和显式菜单；图标选择可在嵌套编辑器中操作。
- 修改点击方式后，另一设置页未保存的探测地址仍保留，且未写入配置；最终测试标签页未捕获控制台 error。

## 验证边界

浏览器使用桌面引擎的窄视口，没有声称完成实体手机触摸、所有浏览器或线上 NAS/WebDAV 端到端验收。管理 Token 对受保护场景的既有授权能力保持不变。锁定状态下导出的 Web JSON 是部分配置，完整备份仍使用 WebDAV。
