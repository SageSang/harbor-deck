## 实现与行为

| 项目 | 结果与维护边界 |
| --- | --- |
| H01 / H02 快速记录转换 | 三个入口共用内容差异判断。源记录含未迁移的名称、地址、备注或图标时拒绝静默复用；批量失败整批不写。单条编辑可另建书签，或明确舍弃差异并复用已有书签。同场景移动到所选组，保留其他场景与共享书签内容。管理 API 新增默认关闭的 `discardConflictingFields`。 |
| H03 分组重命名 | 草稿固定打开时的导航快照、revision、场景和访问版本，回调绑定本次编辑器。412 保留输入且不自动重发。编辑器编号使用组件内计数，兼容普通 HTTP 环境。 |
| H05 扩展连接设置 | 保存携带表单基线 revision，共享锁内比较。旧表单被拒绝并保留输入，提供显式放弃输入后重载。初次迁移和导入保留独立规则。 |
| H06 整站保存 | HTTP PUT 要求有效 system 对象，继续注入当前认证。缺失、null、数组均拒绝且不落盘；初始化及完整恢复的 schema 默认值保持。 |
| H07 手工恢复 | 原会话在排队开始和本地提交边界重检，写入临时文件后、rename 前再次检查。退出或失效时拒绝未提交恢复；自动备份独立运行，已开始的原子替换继续结算。 |
| H08 图标 | UI 新选择保存 canonical key；共享解析兼容旧 PascalCase，API 改备注与快速记录转换可继续使用旧图标。未知新图标仍被拒绝，无全库迁移。 |
| H04 / H09 | 保留已修复的缓存锁/epoch 与启动 Enter 接管路径及现有回归。 |
| H10 / H11 | README 中英文重写，Compose 示例更新为已发布服务端 1.4.28，说明扩展独立发布。隐私政策补充本地快照、清理与迁移文件范围；保留原维护者上下文入口，将来源致谢移到末尾。 |

- README 使用本轮实际页面截图：`screenshots/overview-2026-10.jpg`、`screenshots/bookmark-editor-2026-10.jpg`、`screenshots/scene-manager-2026-10.jpg`。数据为虚构演示，外部网址为公开工具或保留示例域名；未使用个人生产书签。

## 兼容与交付

管理 API 的重复 URL 转换现在可能返回 `409 QUICK_RECORD_CONTENT_CONFLICT`。调用方应读取差异、保留记录后明确处理，不能自动带上舍弃参数重试。已有调用方可使用 `reuseExistingByUrl: false` 保留全部源内容；详细参数见 [管理 API](bookmark-management-api.md)。

README 的 1.4.28 镜像是已发布基线，不包含本轮尚未发布的修复。本记录编写于本地验证完成时，后续提交与推送以 Git 记录为准。源码提交推送与正式发布分开进行；正式发布仍需选择版本并走对应发布通道，部署继续保留原配置挂载、端口和凭据。提交推送不自动授权发布或生产升级。
