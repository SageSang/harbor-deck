# HarborDeck 1.4.26

修复 1.4.25 本地新标签页的两项回归：初始焦点停在地址栏导致页面快捷键不可用，以及自动套用并保存深色主题。

- 新建标签页后直接聚焦页面搜索框；有缓存和无缓存启动均可直接输入。方向键、`/`、Escape、Enter 及 Alt+Shift 场景切换恢复可用。
- 原生新标签页入口在渲染前立即打开扩展自己的本地页面，不等待网络；正式界面出现后仍原位更新，没有独立缓存页或缓存到服务端的来回跳转。
- 慢加载时保留文字、光标与中文组合输入；用户主动进入地址栏或其他标签页后，后台更新不抢焦点。组合输入期间的方向键不触发书签导航。
- 本地模式默认白色 Frost。旧版自动写入的主题偏好不沿用；可在设置中重新选择其他主题，此后会记住主动选择。普通服务端网页的主题不变。

**本轮必须升级扩展才能修复新标签页体验。** 新扩展可配合 1.4.25 服务端使用；Docker 配置、原连接地址、Token、书签与缓存无需重置。同步提供 1.4.26 服务端构建。

Chrome、Edge 各有解压包和 `-store.zip` 商店包；商店包不含 `key`，上传到原有条目。未代为提交商店审核或升级生产容器。

[验证记录](https://github.com/SageSang/harbor-deck/blob/v1.4.26/docs/newtab-focus-validation-2026-10-05.md)：包含真实新建标签页、系统键盘事件、主题切换、输入交接及原有业务流程回归；MacBook 和 Edge 本体尚未在实际设备复核。
