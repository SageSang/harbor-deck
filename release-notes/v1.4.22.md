# HarborDeck 1.4.22

本次包含服务端镜像和 Chrome、Edge 扩展 ZIP。可以先升级服务端，继续使用旧扩展；扩展本地缓存需要两端更新后成功在线加载一次。GitHub 发布不等于商店审核或生产部署。

## 更新内容

- 普通书签、快速记录和分组保留一份本地只读副本。打开时先显示缓存，后台成功后更新；网络失败保留原内容，服务端明确删除或返回空列表时同步更新。
- 扩展新标签页有缓存时可直接离线展示，支持搜索、场景切换及主备链接。已有输入或操作时保留本地视图，手动进入完整页面会携带搜索词和选中场景。
- 密码场景、凭据和 Token 不进入缓存。退出、换账号、清理及地址变更会阻止旧请求重新写回；清理不影响连接设置、编辑草稿或服务端数据。
- 读取请求包含响应体解析在内最多等待 5 秒；明确离线的修改不排队自动补交。沿用现有浏览器存储，没有增加数据库、轮询服务、离线编辑或 Service Worker。
- 修正 HTML 入口返回 304 时丢失内嵌许可的问题，允许已登记的扩展正常重复加载；其他页面和 API 的限制保持不变。这不能证明此前 Mac 启动提示的具体根因。

## 升级与验证

先备份配置，再升级服务端；服务重启后按需重新登录和解锁场景。旧扩展仍可正常打开；只升级服务端不会获得扩展离线列表。普通网页仍需先加载应用资源，完全不可达时从零打开网页不在本次离线能力范围内。

Chrome 下载 `harbor-deck-v1.4.22.zip`，Edge 下载 `harbor-deck-v1.4.22-edge.zip`。两个渠道沿用各自固定身份。更换安装渠道或 ID 前先导出设置与草稿，核对完成前保留旧安装。行为、清理与回退详见仓库 `docs/bookmark-cache.md`。

348 项测试、Lint 和网页、服务端、两渠道扩展构建通过。Linux 隔离 Chromium 完成 Chrome 身份 15 项、Edge 身份 14 项实际浏览器检查，包含弱网、完全离线、重连、删除、过期登录、消息校验及旧版 1.4.21 扩展兼容。Mac 真机、Microsoft Edge 本体、实际商店升级与生产反代仍待验；未部署生产容器或代为提交商店审核。

## English

Ordinary referenced bookmarks and quick records now have one local read-only snapshot per address. Cached lists render before slow reads and remain available after network failure; successful responses, including empty/deleted content, replace them. The extension can open its own cached list fully offline, with search, scene selection and primary/secondary links. User input is preserved when reconnecting or entering the full page.

Protected scenes, credentials and tokens are excluded. Logout, account changes, explicit clearing and address changes invalidate obsolete writes without deleting drafts or connection settings. Reads are bounded to five seconds including body decoding; offline writes are not queued. Existing browser storage is used without a new database, polling service, Service Worker or offline editor. HTML entry revalidation now retains its exact extension embedding policy on 304 responses.

The server may be upgraded before the extension. Both need updating, followed by a successful online load, to establish extension snapshots. Direct web visits still need their application resources to load. Use `harbor-deck-v1.4.22.zip` for Chrome and `harbor-deck-v1.4.22-edge.zip` for Edge. Read `docs/bookmark-cache.md` for cleanup, migration and rollback details.

All 348 tests, lint and builds pass; isolated Chromium checks cover both fixed identities and the previous 1.4.21 extension. Real Mac, Microsoft Edge, actual store upgrades and production proxy verification remain pending. Release assets do not imply store submission or production deployment.
