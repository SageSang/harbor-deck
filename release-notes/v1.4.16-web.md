## 中文

- 将导航分组的展开状态保存到服务端，在内外网地址、同源标签页和不同设备之间共享，不再依赖浏览器扩展或单个地址的本地存储。
- 未初始化、新建和未知分组默认保持折叠；升级时会一次性迁移可判定的旧折叠状态，旧值缺失、为空或损坏时统一初始化为全部折叠。
- 在场景菜单增加“全部展开”和“全部折叠”，搜索期间仅临时展开匹配分组，不写入持久偏好。
- 分组操作采用原子增量更新、乐观交互和失败回滚，并修复跨标签页响应乱序可能覆盖较新状态的问题。

## English

- Moved navigation group expansion preferences to the server so LAN and WAN URLs, same-origin tabs, and different devices share one state without depending on the browser extension or per-origin local storage.
- Uninitialized, newly created, and unknown groups now stay collapsed by default. Upgrades migrate determinable legacy collapse state once, while missing, empty, or malformed legacy values initialize to all collapsed.
- Added Expand All and Collapse All commands to the scene menu. Search matches expand temporarily without changing persisted preferences.
- Added atomic incremental updates, optimistic interactions, failure rollback, and protection against out-of-order cross-tab responses overwriting newer state.
