## 中文

- 新增独立管理 Token 的 `/api/management/v1` 书签管理 API，支持读取和整理全部场景中的分组、书签、位置顺序和快速记录。
- 管理接口支持完整 CRUD、批量放置/移动/移除、复制、图标补全、搜索、Dry-run 预演以及 OpenAPI 3.1 契约。
- 所有写入使用 ETag/`If-Match` revision 并发保护，配置文件采用串行读改写和原子替换，避免旧状态覆盖新修改。
- 管理 Token 与搜索 Token、管理员登录和场景密码完全分离；敏感字段不返回，接口默认关闭，响应不缓存并对 Token 日志脱敏。
- 本版本为 Web/Docker 发布，不包含浏览器扩展更新。

## English

- Added the independent-token `/api/management/v1` bookmark management API for reading and organizing groups, bookmarks, placements, ordering, and quick records across all scenes.
- Added full CRUD, batch placement/move/remove, duplication, icon filling, search, dry-run previews, and an OpenAPI 3.1 contract.
- All writes use ETag/`If-Match` revision concurrency protection, with serialized read-modify-write and atomic config replacement to prevent stale overwrites.
- Management authentication is separate from the search token, administrator login, and scene passwords. Sensitive fields are excluded, the API is disabled by default, responses are not cached, and management tokens are redacted from logs.
- This is a Web/Docker release; it does not include a browser extension update.
