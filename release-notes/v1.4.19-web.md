## 中文

- 修复跨标签页分组偏好同步循环、并发保存覆盖和后台刷新丢失未保存草稿的问题。
- 锁定场景的 Web 配置读取只返回必要占位信息；保存公开内容时保留私密数据，并要求解锁后才能修改受保护内容。
- 修复长周期 WebDAV 自动备份的计时器溢出，并让普通配置保存不再等待远端调度刷新。
- 优化本机主题记忆、网络探测与备用地址选择、快速记录整理、搜索、书签链接和窄屏/键盘交互。
- 本版本为 Web/Docker 发布，不包含浏览器扩展更新。

## English

- Fixed cross-tab group-preference request loops, stale concurrent saves, and background refreshes overwriting unsaved drafts.
- Locked scenes now expose only necessary Web placeholders; visible-content saves preserve private data, and protected content requires unlocking before editing.
- Fixed timer overflow for long WebDAV backup intervals and decoupled normal configuration saves from remote schedule refreshes.
- Improved local browser theme persistence, network probing and alternate-URL selection, quick-record organization, search, bookmark links, and narrow-screen/keyboard interactions.
- This is a Web/Docker release; it does not include a browser extension update.
