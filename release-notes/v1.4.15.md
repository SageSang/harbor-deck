## 中文

- 新增 Midnight、Frost 和 Ember 三套应用皮肤，网页端与 Chrome 插件均可切换，并通过受 Token 保护的接口同步网站最近保存的配色。
- 重构网页端和插件端的视觉系统，引入统一 Design Tokens、毛玻璃层次、Bento 布局和更平滑的交互动效。
- 新标签页启动壳会在首帧应用缓存皮肤，并把皮肤和提前输入的查询内容交接给导航页，减少浅色主题下的黑屏闪烁，同时保留即时输入体验。
- 完善分组折叠偏好的本地持久化和旧数据迁移，能够区分“未设置偏好”和“明确全部展开”。

## English

- Added Midnight, Frost, and Ember app skins across the web app and Chrome extension, with token-protected synchronization of the latest website color scheme.
- Reworked the visual system with shared design tokens, layered glass surfaces, Bento layouts, and smoother interaction transitions.
- The new-tab startup shell now applies the cached skin on the first frame and hands both the skin and early search input to the navigation page, reducing dark flashes in light mode without losing instant typing.
- Improved local persistence and legacy migration for group collapse preferences, distinguishing an unset preference from an explicitly fully expanded state.
