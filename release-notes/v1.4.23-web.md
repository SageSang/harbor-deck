# HarborDeck 1.4.23 — keyboard navigation fix

修复导航页方向键跳过邻近分组或落入错误行的问题。例如从 Docker Hub 向下，现在先进入相邻 Synology 行，而不会因 iKuai 卡片横向更对齐就越过整个分组。

- 上下键先选择最近的可见行，再选择横向位置最接近的卡片。
- 左右键优先在同一可见行移动，行首/行尾保留原有显示顺序换行。
- 隐藏、折叠或没有有效布局的卡片不会成为目标；顶部/底部返回搜索框及 Escape、修饰键行为保留。
- 每次按键读取当前布局，适应窗口宽度和分组卡片宽度差异，无新增依赖、设置或持久状态。

这是网页/服务端发布，现有 1.4.22 扩展可继续使用，无需重新安装或提交商店。升级镜像为 `ghcr.io/sagesang/harbor-deck:1.4.23`，重开导航页；必要时刷新已打开页面。保留原端口、挂载及环境变量。服务重启后需要重新登录。

356 项测试、Lint、网页和服务端构建通过。隔离 Linux Chrome 152 实际复现旧行为，并在修复后验证 7 种宽度下 24 张卡片的四方向路径（672 次检查），以及折叠、搜索、空结果、边界返回搜索和修饰键。生产服务器和 Mac/Edge 真机尚未现场验证。本次发布不等于已升级生产容器。

## English

Arrow navigation now selects the adjacent visible row before the closest horizontal position. This prevents a more precisely aligned card in a distant group from winning over nearby bookmarks. Left/right navigation stays within the visual row before retaining reading-order wrapping. Hidden or unmeasurable cards are excluded; search boundaries, Escape and modified shortcuts remain unchanged.

The fix uses current element geometry on each keypress without additional dependencies, settings or persistent state. This is a web/server-only release; existing 1.4.22 extensions remain compatible. Update the server image to `ghcr.io/sagesang/harbor-deck:1.4.23` and reload the navigation page.

All 356 tests, lint and web/server builds pass. Isolated Linux Chrome reproduced the original skip and verified 672 directional moves across seven viewport widths, plus filtering, collapsed groups and search boundaries. Production deployment and physical Mac/Edge validation were not performed.
