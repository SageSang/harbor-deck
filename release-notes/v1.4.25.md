# HarborDeck 1.4.25

本版作为统一新标签页的最终交付，补齐候选1.4.24的设置迁移边界：只修改超时并保存时，保持界面显示的本地模式；明确选择直达仍会保留。

新标签页改为本地运行正式前端：有缓存直接显示同一导航界面，联网后原位更新；无缓存保留可输入的过渡界面，并接续文字、光标和中文组合输入。移除独立缓存页与隐藏 iframe 交接。

- 保留完整在线编辑、受保护场景、搜索、场景切换和方向键导航。缓存只用于普通内容展示，不会作为完整配置提交。
- 实际 API 读取不再被短时健康探测拦住；主备连接优先复用可用登录，写请求不跨地址重放。
- 修正收藏弹窗对扩展设置页的处理，保留未完成及结果不确定的收藏草稿。
- 保留地址、Token 和检测时限。旧打开模式默认使用本地页面；需要直达时在新设置里明确选择并保存。
- 服务端配置格式不变，可以先升级服务端。旧扩展仍可使用现有入口；新体验须更新扩展。正式页面资源和缓存机制详见 [使用说明](https://github.com/SageSang/harbor-deck/blob/v1.4.25/docs/bookmark-cache.md)。

Chrome、Edge 分别提供解压安装包与 `-store.zip` 商店包。商店包不含 `key`，请上传至原有条目。

回归范围与实际设备边界见 [验证记录](https://github.com/SageSang/harbor-deck/blob/v1.4.25/docs/unified-newtab-validation-2026-10-02.md)。未代为升级生产容器或提交商店审核。
