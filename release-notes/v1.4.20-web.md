## 中文

- 修复保护场景的书签隔离：搜索/收藏接口仅复用可见书签，Web 保存拒绝未授权的隐藏书签引用；保留正常共享和独立管理 Token 的全场景能力。
- 修复初始化、改密和场景解锁的并发处理；改密保留同期系统设置，恢复配置后及时撤销必要访问，登录限流正确处理在途请求和可信反代客户端。
- 保存单个分组不再清除其他草稿，新建或复制后保持正确场景；保存成功但页面同步失败时可只重新读取，不重复写入。
- WebDAV 完整响应受超时约束，远端故障不阻止服务启动；上传成功与旧版本清理失败分别提示，并改进恢复与正常关闭顺序。
- 新增四个原始标识请求体管理入口，支持历史长书签标识的修改、删除、复制和位置调整；不自动改写历史配置、标识或共享引用。
- 可选环境变量：`HARBORDECK_TRUSTED_EXTENSION_IDS` 登记允许内嵌的 Chrome 扩展 ID；`HARBORDECK_WEBDAV_TIMEOUT_MS` 设置单个 WebDAV 请求超时，默认 15000 毫秒。

升级前备份完整配置。服务重启后需重新登录并解锁场景；现有 Token 不变。本次发布服务端镜像，不发布浏览器扩展资产。真实 Chrome 内嵌/权限/Cookie、目标反代和实际升级中断需按环境验收。

验证：288 项测试、lint、Web/服务端与扩展构建通过；隔离 amd64 容器完成登录、配置读写、WebDAV 备份恢复及正常关闭检查。生产依赖审计为 0 项告警，开发测试工具链仍有待单独处理的告警。

## English

- Fix protected-scene bookmark isolation in integration lookup/collection and Web saves while preserving intentional sharing and the independent management token's access.
- Make setup, credential changes and scene unlocking concurrency-safe; preserve simultaneous settings edits, invalidate access promptly after restores, and account for in-flight login attempts and trusted proxy clients.
- Preserve other group drafts when saving one name, keep newly created/copied scenes selected, and retry page synchronization without repeating successful writes.
- Apply WebDAV deadlines to complete responses, start the service independently of remote scheduling, distinguish upload success from cleanup warnings, and improve restore/shutdown ordering.
- Add four request-body management endpoints for historical long bookmark identifiers without rewriting existing identifiers, configuration or shared references.
- Add optional `HARBORDECK_TRUSTED_EXTENSION_IDS` and `HARBORDECK_WEBDAV_TIMEOUT_MS` deployment settings; the latter defaults to 15000 ms per request.

Back up the full configuration before upgrading. Restarting requires signing in and unlocking scenes again; existing tokens remain valid. This release publishes the server image only. Chrome embedding/permissions/cookies, the target reverse proxy and actual upgrade downtime still require environment-specific acceptance.

Validation: 288 tests, lint and all builds passed; an isolated amd64 container passed authentication, configuration, WebDAV backup/restore and graceful shutdown checks. Production dependency audit reports zero advisories; development-tool advisories remain separate follow-up work.
