# HarborDeck 1.4.21

本次包含服务端镜像及 Chrome、Edge 扩展 ZIP。可以先升级服务端，继续使用旧扩展，再等待商店版本更新；GitHub 发布不等于已提交或通过商店审核。

## 更新内容

- Chrome、Edge 标准包分别沿用既有商店 ID；服务端默认允许这两个精确来源内嵌。原有额外扩展白名单继续生效，留空现表示“没有额外 ID”。普通页面、API、登录及场景权限保持原有边界。
- 扩展连接设置改为按设备保存，首次升级接续本机可见的旧同步值；之后其他设备的同步不会覆盖本机地址、Token、打开方式和超时。语言仍沿用同步设置。
- 提供设置与草稿的本地导入导出，以及旧版只读导出工具。迁移文件不含 Token，非空目标拒绝覆盖，未确认的收藏请求不会自动重发。
- 启动页增加“重新检测并打开”，继续保护输入并取消过期尝试；失败时显示每个地址的超时、HTTP、权限或网络结果及耗时。
- 新安装默认探测时限为 1000 毫秒；已保存的值保持不变。原有 120 毫秒热路径输入保护不变。

## 升级与验证

先备份配置，再升级服务端；保留旧解压版使用的额外允许 ID。服务重启后需重新登录和解锁场景。只升级服务端不会自动获得扩展侧的恢复、诊断和本机设置能力。

Chrome 下载 `harbor-deck-v1.4.21.zip`，Edge 下载 `harbor-deck-v1.4.21-edge.zip`。更换安装渠道或 ID 前先导出数据，核对完成前保留旧安装。详细步骤见仓库 `docs/extension-local-settings-and-recovery.md`。

329 项测试、Lint 和各项构建通过；隔离 Chromium 已验证两个标准身份的内嵌登录、场景权限、退出、未登记来源拒绝，以及旧 ID 数据迁移和启动恢复。Mac 真机、Edge 本体、实际商店升级及生产反代仍待验；本次没有部署生产容器，也没有代为提交商店审核。

## English

- Chrome and Edge packages now retain their respective store identities. The server allows these two exact origins by default for the existing embedded HTML entry; custom trusted IDs remain supported. Empty trusted-ID configuration now means no additional IDs.
- Connection settings become device-local after a one-time migration from old sync values. Language keeps its existing sync behavior. Verify the current device's addresses after upgrade.
- Settings and unfinished drafts can be exported/imported locally, without tokens. Non-empty targets are not overwritten. A read-only exporter is included for old versions; keep the old installation until data is verified.
- A paused new-tab page offers **Check again and open**, preserving input and cancelling stale attempts. Per-address check results distinguish timeout, HTTP, permission and network failures.
- New installations default to a 1000 ms check timeout. Existing saved values are preserved. The 120 ms warm opening guard remains unchanged.

The server can be upgraded before the extension. Existing extensions keep their APIs and custom trusted IDs; extension-side improvements require the extension update. Restarting the server requires signing in and unlocking scenes again. Chrome uses `harbor-deck-v1.4.21.zip`; Edge uses `harbor-deck-v1.4.21-edge.zip`.

Read the migration and rollback guide before changing an extension ID. Real Mac, Microsoft Edge, actual store upgrades and production proxy validation are still pending; local Chromium checks do not represent those environments. GitHub release assets do not imply store submission or approval, or a production deployment.
