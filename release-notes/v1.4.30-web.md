## 中文

- 修复浏览器捕获或集成 API 归组时丢弃快速记录独有内容的问题；名称、备注、备用地址等存在差异时保留原记录，供后续明确处理。
- 明确指定的快速记录场景不存在或已受保护时拒绝保存，避免悄悄写入默认场景。
- 包含此前主分支中的书签编辑与分组重命名恢复、备份恢复保护，以及历史图标名称兼容修复。
- 本次更新 Web 服务端镜像，浏览器扩展无需更新。

## English

- Preserve quick records with distinct titles, notes, fallback URLs, or other content when browser capture or the integration API places a bookmark into a group.
- Reject captures targeting an explicitly selected scene that no longer exists or is protected, instead of silently saving to the default scene.
- Include the existing main-branch fixes for bookmark editing and group rename recovery, backup restoration safeguards, and historical icon names.
- This release updates the web/server image. No browser extension update is required.
