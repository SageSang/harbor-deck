## 中文

- 优化桌面端书签卡片布局：小分组中的卡片会适当加宽，图标保持垂直居中，长名称最多展示三行；书签较多的分组仍保留紧凑的 6/8 列布局。
- 在“分组管理”顶部增加一次性的“补全旧书签图标”入口，只为仍缺少图标的旧书签和快速记录分配随机图标，已有图标不会改变。
- 图标补全成功后入口会自动消失；受保护且未解锁的场景不会被修改，共享到这些场景的书签也会安全跳过。
- 浏览器扩展与 Docker 镜像同步发布为 1.4.9。

## English

- Improve desktop bookmark cards with wider compact sizing, vertically centered icons, and up to three lines for long names, while keeping dense 6/8-column layouts for larger groups.
- Add a one-time “Fill Missing Legacy Icons” action at the top of Group Management. It assigns random icons only to older bookmarks and quick records that still lack one, leaving existing icons unchanged.
- Hide the migration entry automatically after completion. Protected scenes stay unchanged unless unlocked, and bookmarks shared with those scenes are skipped safely.
- Publish browser extension and Docker image version 1.4.9 together.
