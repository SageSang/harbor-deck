## 中文

- 新标签页在应用加载前立即显示并聚焦搜索框，加载期间输入的内容会完整交接给主页面，不再丢失开页瞬间的输入。
- 修复扩展重复保存现有书签或快速记录时，名称、地址和备注没有按当前输入更新的问题。
- 修复快速记录编辑后仍能通过已删除内容或内部记录标识搜索到的问题。
- 完善键盘导航：从最后一个书签继续向下会回到搜索框，第一行向上会直接返回搜索框，并保留网格内的方向移动。
- 加固外部访问安全：限制可打开地址为 HTTP/HTTPS，防止集成响应泄露导航配置，阻止伪造代理 IP 绕过登录限速，并增加 CSP、安全响应头、API 禁止缓存和受信代理配置。
- 更新 Fastify、静态文件服务和相关运行依赖；Docker Compose 示例默认只在宿主机 `127.0.0.1:8080` 监听，适合通过 HTTPS 反向代理访问。
- 浏览器扩展与 Docker 镜像同步发布为 1.4.8。

## English

- Show and focus the new-tab search field before the application loads, then hand off everything typed during startup without losing early keystrokes.
- Fix extension saves of existing bookmarks and quick records so the current name, URLs, and note are actually applied.
- Remove stale quick-record search matches after edited text is deleted, and keep internal record identifiers out of search indexing.
- Complete keyboard navigation: Arrow Down from the last bookmark returns to search, Arrow Up from the first row returns directly to search, and directional movement inside the grid remains intact.
- Harden external access by allowing only HTTP/HTTPS targets, removing navigation data from integration write responses, preventing proxy-header and username rotation from bypassing login throttling, and adding CSP, security headers, API no-store responses, and explicit trusted-proxy configuration.
- Update Fastify, static serving, and related runtime dependencies. The Docker Compose example now binds host `127.0.0.1:8080` by default for use behind an HTTPS reverse proxy.
- Publish browser extension and Docker image version 1.4.8 together.
