# HarborDeck 1.4.27 — Extension

扩展保存位置现在支持搜索，直接跳转新标签页在短暂连接失败后能自动恢复。本次仅发布扩展，服务端及 Docker 镜像不更新；继续兼容现有 1.4.25 及后续服务端接口。

- 按场景和分类完整路径搜索，支持中英文及多个关键词，例如“Home 邮箱”。搜索、展开和收起均保留已选位置，同一场景内替换分类，跨场景选择继续保留。
- 已选位置清晰显示，快速记录目标明确选择；标题与地址保持可见，更多信息按需展开，长备注和分类列表不会遮挡保存按钮。
- 恢复草稿时遇到已删除或合并的分类，会保留输入并要求重新选择。未确认的提交先只读核对，明确恢复编辑也不会自动重发。
- 直接跳转模式为后台唤醒预留等待时间，首次临时失败后自动补测一次，接收晚到的有效成功结果。恢复联网或重新显示页面可再次检测，持续离线不会无限轮询。
- 恢复跳转保留已输入内容并等待中文组合输入结束，防止重复跳转和使用旧设置的结果。健康检查会识别登录页及无效响应。

现有地址、Token、扩展身份、场景和草稿沿用；网页书签搜索仍只覆盖当前场景。

## English

This extension-only release adds searchable scene/group destinations and bounded recovery for direct new tabs. Selections survive filtering, quick-record destinations are explicit, and the save button stays accessible with long notes. Invalid draft destinations require repair; checking an uncertain submission and resuming editing never automatically resubmits it.

Direct mode allows service-worker startup time, retries an initial transient failure once, accepts late matching successes, and responds to online/visibility recovery. Navigation preserves input, waits for IME composition, and ignores stale settings. Health probes reject login HTML and invalid JSON.

Use the channel-specific `-store.zip` for the existing store listing, or the corresponding ZIP without `-store` for unpacked installation. No server image, production deployment, or store submission is included. Existing connection settings, identities and current-scene bookmark search remain unchanged. Mac native-device validation is still outstanding.
